WANDERLUST LEADERSHIP LIBRARY

Upload every item in this folder to the root of the existing
wanderlust-leadership-library GitHub repository.

Required structure:

index.html
styles.css
acquisition/index.html
construction/index.html
home-transition/index.html
business-management/index.html

Cloudflare Pages will deploy the update automatically after the GitHub commit.
Do not create additional Cloudflare projects, custom domains, or DNS records for
the four category pages.

Future manuals should be placed inside the appropriate category folder, each in
its own folder with an index.html file.
